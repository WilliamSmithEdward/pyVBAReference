# PickerFields

**Type:** Dispatch Interface  
**Library:** Microsoft Office 16.0 Object Library  
**GUID:** {000C03E1-0000-0000-C000-000000000046}  

A collection of PickerField objects. Each PickerField object represents a column definition of PickerDialog.

## Properties (5)

- `Application As Object  (read-only)`  
  Gets an Application object that represents the container application for the PickerFields object. Read-only.
- `Creator As Long  (read-only)`  
  Gets a 32-bit integer that indicates the application in which the PickerFields object was created. Read-only.
- `Item As PickerField  (read-only)`  
  Retrieves a PickerField object at the specified index. Read-only.
- `Count As Long  (read-only)`  
  Retrieves the count of the number of PickerField objects contained within the PickerFields collection. Read-only.
- `_NewEnum As IUnknown  (read-only)`
