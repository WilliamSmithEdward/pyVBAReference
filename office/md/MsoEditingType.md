# MsoEditingType

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the editing type of a node.

## Constants (4)

- `msoEditingAuto` = 0  
  Changes the node to a type appropriate to the segments being connected.
- `msoEditingCorner` = 1  
  Changes the node to a corner node.
- `msoEditingSmooth` = 2  
  Changes the node to a smooth curve node.
- `msoEditingSymmetric` = 3  
  Changes the node to a symmetric curve node.
