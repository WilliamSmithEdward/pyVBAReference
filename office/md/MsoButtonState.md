# MsoButtonState

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the appearance of a command bar button control.

## Constants (3)

- `msoButtonUp` = 0  
  Button is not pressed down.
- `msoButtonDown` = -1  
  Button is pressed down.
- `msoButtonMixed` = 2  
  Button is pressed down.
