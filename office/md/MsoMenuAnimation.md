# MsoMenuAnimation

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the animation style for Microsoft Office command bars.

## Constants (4)

- `msoMenuAnimationNone` = 0  
  No animation
- `msoMenuAnimationRandom` = 1  
  Random animation
- `msoMenuAnimationUnfold` = 2  
  Menus unfold into view
- `msoMenuAnimationSlide` = 3  
  Menus slide into view
