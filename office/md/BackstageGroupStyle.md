# BackstageGroupStyle

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies constants that define the styles of the groups on the File tab.

## Constants (3)

- `BackstageGroupStyleNormal` = 0  
  Normal style
- `BackstageGroupStyleWarning` = 1  
  Warning style
- `BackstageGroupStyleError` = 2  
  Error style
