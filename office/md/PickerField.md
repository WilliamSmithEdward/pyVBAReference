# PickerField

**Type:** Dispatch Interface  
**Library:** Microsoft Office 16.0 Object Library  
**GUID:** {000C03E0-0000-0000-C000-000000000046}  

Represents the field definitions of sub-items in a PickerResult object. Each PickerField object represents a column definition of a PickerDialog.

## Properties (5)

- `Application As Object  (read-only)`  
  Gets an Application object that represents the container application for the PickerField object. Read-only.
- `Creator As Long  (read-only)`  
  Gets a 32-bit integer that indicates the application in which the PickerField object was created. Read-only.
- `Name As String  (read-only)`  
  Retrieves the name of the PickerField. Read-only.
- `Type As MsoPickerField  (read-only)`  
  The type of the PickerField. Read-only.
- `IsHidden As Boolean  (read-only)`  
  Specifies whether the PickerField is hidden. Read-only.
