# XlBarShape

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the shape used with the 3D bar or column chart.

- `xlPyramidToMax` = 2  
  Pyramid, truncated at value.
- `xlCylinder` = 3  
  Cylinder.
- `xlConeToPoint` = 4  
  Cone, coming to point at value.
- `xlConeToMax` = 5  
  Cone, truncated at value.
