# XlCubeFieldType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies whether the OLAP field is a hierarchy, set, or measure field.

## Constants (3)

- `xlHierarchy` = 1  
  OLAP field is a hierarchy.
- `xlMeasure` = 2  
  OLAP field is a measure.
- `xlSet` = 3  
  OLAP field is a set.
