# XlSaveAsAccessMode

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the access mode for the Save As function.

## Constants (3)

- `xlExclusive` = 3  
  Exclusive mode
- `xlNoChange` = 1  
  Default (does not change the access mode)
- `xlShared` = 2  
  Share list
