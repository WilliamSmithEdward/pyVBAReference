# XlArrowHeadWidth

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the width of the arrowhead at the end of a line.

## Constants (3)

- `xlArrowHeadWidthMedium` = -4138  
  Medium-width arrowhead
- `xlArrowHeadWidthNarrow` = 1  
  Narrowest arrowhead
- `xlArrowHeadWidthWide` = 3  
  Widest arrowhead
