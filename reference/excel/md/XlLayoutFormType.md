# XlLayoutFormType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the way the specified PivotTable items appear&mdash;in table format or in outline format.

## Constants (2)

- `xlTabular` = 0  
  Default.
- `xlOutline` = 1  
  The LayoutSubtotalLocation property specifies where the subtotal appears in the PivotTable report.
