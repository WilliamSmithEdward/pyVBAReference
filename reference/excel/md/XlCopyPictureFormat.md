# XlCopyPictureFormat

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the format of the picture being copied.

## Constants (2)

- `xlBitmap` = 2  
  Picture copied in bitmap (raster) format: bmp, jpg, gif, png.
- `xlPicture` = -4147  
  Picture copied in vector format: emf, wmf.
