# XlTimelineLevel

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

One of the built-in hierarchy levels that Timeline supports.

## Constants (4)

- `xlTimelineLevelYears` = 0  
  Years level
- `xlTimelineLevelQuarters` = 1  
  Quarters level
- `xlTimelineLevelMonths` = 2  
  Months level
- `xlTimelineLevelDays` = 3  
  Days level
