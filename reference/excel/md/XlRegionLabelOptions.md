# XlRegionLabelOptions

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Constants passed to and returned by the Series.RegionLabelOptions property.

## Constants (3)

- `xlRegionLabelOptionsNone` = 0  
  Don't show region labels.
- `xlRegionLabelOptionsBestFitOnly` = 1  
  Only show labels that can be fitted within the bounds of their regions.
- `xlRegionLabelOptionsShowAll` = 2  
  Show all region labels.
