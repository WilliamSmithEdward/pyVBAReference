# XlSearchOrder

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the order in which to search the range.

## Constants (2)

- `xlByColumns` = 2  
  Searches down through a column, then moves to the next column.
- `xlByRows` = 1  
  Searches across a row, then moves to the next row.
