# XlSpecialCellsValue

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies cells with a particular type of value to include in the result.

## Constants (4)

- `xlErrors` = 16  
  Cells with errors.
- `xlLogical` = 4  
  Cells with logical values.
- `xlNumbers` = 1  
  Cells with numeric values.
- `xlTextValues` = 2  
  Cells with text.
