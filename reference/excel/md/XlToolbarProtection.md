# XlToolbarProtection

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies which properties of a toolbar are restricted. Options can be combined using Or.

## Constants (5)

- `xlNoButtonChanges` = 1  
  No button changes permitted.
- `xlNoChanges` = 4  
  No changes of any kind.
- `xlNoDockingChanges` = 3  
  No changes to toolbar's docking position.
- `xlToolbarProtectionNone` = -4143  
  All changes permitted.
- `xlNoShapeChanges` = 2  
  No changes to toolbar shape.
