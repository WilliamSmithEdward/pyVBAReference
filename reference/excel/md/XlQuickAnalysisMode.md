# XlQuickAnalysisMode

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Indicates for which top level button the callout user interface is displayed.

## Constants (6)

- `xlLensOnly` = 0  
  Show the button but no callout user interface
- `xlFormatConditions` = 1  
  Conditional Formatting
- `xlRecommendedCharts` = 2  
  Charts
- `xlTotals` = 3  
  Totals
- `xlTables` = 4  
  Tables
- `xlSparklines` = 5  
  Sparklines
