# XlMousePointer

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the appearance of the mouse pointer in Excel.

## Constants (4)

- `xlIBeam` = 3  
  The I-beam pointer.
- `xlDefault` = -4143  
  The default pointer.
- `xlNorthwestArrow` = 1  
  The northwest-arrow pointer.
- `xlWait` = 2  
  The hourglass pointer.
