# XlAutoFilterOperator

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the operator to use to associate two criteria applied by a filter.

- `xlBottom10Items` = 4

- `xlTop10Items` = 3

- `xlTop10Percent` = 5
