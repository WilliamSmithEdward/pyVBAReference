# XlListObjectSourceType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the current source of the list.

## Constants (5)

- `xlSrcExternal` = 0  
  External data source (Microsoft SharePoint Foundation site).
- `xlSrcRange` = 1  
  Range
- `xlSrcXml` = 2  
  XML
- `xlSrcQuery` = 3  
  Query
- `xlSrcModel` = 4  
  PowerPivot Model
