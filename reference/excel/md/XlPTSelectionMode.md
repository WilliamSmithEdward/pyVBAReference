# XlPTSelectionMode

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies what can be selected in a PivotTable during a structured selection. These constants can be combined to select multiple types.

## Constants (7)

- `xlLabelOnly` = 1  
  Label
- `xlDataAndLabel` = 0  
  Data and labels
- `xlDataOnly` = 2  
  Data
- `xlOrigin` = 3  
  Origin
- `xlButton` = 15  
  Buttons
- `xlBlanks` = 4  
  Blanks
- `xlFirstRow` = 256  
  First row
