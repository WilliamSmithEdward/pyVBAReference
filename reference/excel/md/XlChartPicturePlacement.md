# XlChartPicturePlacement

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the placement of a user-selected picture on a bar in a 3D bar or column.

## Constants (7)

- `xlSides` = 1  
  Display on sides.
- `xlEnd` = 2  
  Display on end.
- `xlEndSides` = 3  
  Display on end and sides.
- `xlFront` = 4  
  Display on front.
- `xlFrontSides` = 5  
  Display on front and sides.
- `xlFrontEnd` = 6  
  Display on front and end.
- `xlAllFaces` = 7  
  Display on all faces.
