# XlTickMark

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the position of major and minor tick marks for an axis.

## Constants (4)

- `xlTickMarkCross` = 4  
  Crosses the axis
- `xlTickMarkInside` = 2  
  Inside the axis
- `xlTickMarkNone` = -4142  
  No mark
- `xlTickMarkOutside` = 3  
  Outside the axis
