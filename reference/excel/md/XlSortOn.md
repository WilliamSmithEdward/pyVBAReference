# XlSortOn

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the parameter on which the data should be sorted.

## Constants (4)

- `xlSortOnValues` = 0  
  Values.
- `xlSortOnCellColor` = 1  
  Cell color.
- `xlSortOnFontColor` = 2  
  Font color.
- `xlSortOnIcon` = 3  
  Icon.
