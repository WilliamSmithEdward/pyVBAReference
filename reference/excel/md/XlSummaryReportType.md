# XlSummaryReportType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the type of summary to be created for scenarios.

## Constants (2)

- `xlSummaryPivotTable` = -4148  
  Display scenarios in a PivotTable report.
- `xlStandardSummary` = 1  
  List scenarios side by side.
