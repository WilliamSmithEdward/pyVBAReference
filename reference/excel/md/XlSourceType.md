# XlSourceType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Identifies the source object.

## Constants (8)

- `xlSourceWorkbook` = 0  
  A workbook
- `xlSourceSheet` = 1  
  An entire worksheet
- `xlSourcePrintArea` = 2  
  A range of cells selected for printing
- `xlSourceAutoFilter` = 3  
  An AutoFilter range
- `xlSourceRange` = 4  
  A range of cells
- `xlSourceChart` = 5  
  A chart
- `xlSourcePivotTable` = 6  
  A PivotTable report
- `xlSourceQuery` = 7  
  A query table (external data range)
