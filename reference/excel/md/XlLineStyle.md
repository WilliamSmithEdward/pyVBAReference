# XlLineStyle

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the line style for the border.

## Constants (8)

- `xlContinuous` = 1  
  Continuous line.
- `xlDash` = -4115  
  Dashed line.
- `xlDashDot` = 4  
  Alternating dashes and dots.
- `xlDashDotDot` = 5  
  Dash followed by two dots.
- `xlDot` = -4118  
  Dotted line.
- `xlDouble` = -4119  
  Double line.
- `xlSlantDashDot` = 13  
  Slanted dashes.
- `xlLineStyleNone` = -4142  
  No line.
