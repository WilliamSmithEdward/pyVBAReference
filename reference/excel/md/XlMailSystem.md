# XlMailSystem

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the mail system that is installed on the host computer.

## Constants (3)

- `xlMAPI` = 1  
  MAPI-complaint system
- `xlNoMailSystem` = 0  
  No mail system
- `xlPowerTalk` = 2  
  PowerTalk mail system
