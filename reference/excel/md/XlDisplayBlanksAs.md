# XlDisplayBlanksAs

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies how blank cells are plotted on a chart.

## Constants (3)

- `xlInterpolated` = 3  
  Values are interpolated into the chart.
- `xlNotPlotted` = 1  
  Blank cells are not plotted.
- `xlZero` = 2  
  Blanks are plotted as zero.
