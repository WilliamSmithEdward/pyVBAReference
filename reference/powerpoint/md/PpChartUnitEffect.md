# PpChartUnitEffect

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies whether the graph range is animated by series, category, or element.

## Constants (6)

- `ppAnimateChartMixed` = -2  
  Chart mixed
- `ppAnimateBySeries` = 1  
  By series
- `ppAnimateByCategory` = 2  
  By category
- `ppAnimateBySeriesElements` = 3  
  By series elements
- `ppAnimateByCategoryElements` = 4  
  By category elements
- `ppAnimateChartAllAtOnce` = 5  
  Chart all at once
