# XlVAlign

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the vertical alignment for the object.

## Constants (5)

- `xlVAlignBottom` = -4107  
  Bottom alignment.
- `xlVAlignCenter` = -4108  
  Center alignment.
- `xlVAlignDistributed` = -4117  
  Distributed alignment.
- `xlVAlignJustify` = -4130  
  Justified alignment.
- `xlVAlignTop` = -4160  
  Top alignment.
