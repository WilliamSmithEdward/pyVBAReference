# PpBaselineAlignment

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the base line alignment for a paragraph.

## Constants (6)

- `ppBaselineAlignMixed` = -2  
  Mixed alignment.
- `ppBaselineAlignBaseline` = 1  
  Aligned to the baseline.
- `ppBaselineAlignTop` = 2  
  Aligned to the top.
- `ppBaselineAlignCenter` = 3  
  Aligned to the center.
- `ppBaselineAlignFarEast50` = 4  
  Align FarEast50.
- `ppBaselineAlignAuto` = 5
