# XlLineStyle

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the line style for the border.

## Constants (8)

- `xlContinuous` = 1  
  A continuous line.
- `xlDash` = -4115  
  A dashed line.
- `xlDashDot` = 4  
  Alternating dashes and dots.
- `xlDashDotDot` = 5  
  A dash followed by two dots.
- `xlDot` = -4118  
  A dotted line.
- `xlDouble` = -4119  
  A double line.
- `xlSlantDashDot` = 13  
  Slanted dashes.
- `xlLineStyleNone` = -4142  
  No line.
