# PpTextLevelEffect

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the paragraph level by which text effects are animated, passed to and returned by the TextLevelEffect property of the AnimationSettings object.

## Constants (8)

- `ppAnimateLevelMixed` = -2  
  Mixed level
- `ppAnimateLevelNone` = 0  
  No level
- `ppAnimateByFirstLevel` = 1  
  By first level
- `ppAnimateBySecondLevel` = 2  
  By second level
- `ppAnimateByThirdLevel` = 3  
  By third level
- `ppAnimateByFourthLevel` = 4  
  By fourth level
- `ppAnimateByFifthLevel` = 5  
  By fifth level
- `ppAnimateByAllLevels` = 16  
  By all levels
