# TableStyle

**Type:** Dispatch Interface  
**Library:** Microsoft PowerPoint 16.0 Object Library  
**GUID:** {914934F5-5A91-11CF-8700-00AA0060263B}  

Represents the current table style.

**Remarks:** Use the Name property to return the name of the table style. Use the Id property to return the numeric identifier of the table style.

## Properties (2)

- `Name As String  (read-only)`  
  Returns the name of the table style. Read-only.
- `Id As String  (read-only)`  
  Returns a string that identifies the table style. Read-only.
