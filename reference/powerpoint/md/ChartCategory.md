# ChartCategory

**Type:** Dispatch Interface  
**Library:** Microsoft PowerPoint 16.0 Object Library  
**GUID:** {AF028401-4619-4271-AFDD-F480FA925186}  

Represents all chart categories in the document, whether visible (unfiltered) or not.

**Remarks:** Use the IsFiltered property to determine which categories are visible and which are filtered out.

## Properties (3)

- `Parent As Object  (read-only)`  
  Returns the parent for the specified object. Read-only Object.
- `Name As String  (read-only)`  
  Returns or sets a String that represents the name of a chart category. Read/write.
- `IsFiltered As Boolean  (read/write)`  
  Returns or sets a Boolean that determines whether the specified chart category is filtered out from the chart. Read/write.
