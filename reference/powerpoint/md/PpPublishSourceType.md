# PpPublishSourceType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the type of source material to be published, passed to and returned by the SourceType property of the PublishObject object.

## Constants (3)

- `ppPublishAll` = 1  
  Publish all.
- `ppPublishSlideRange` = 2  
  Publish a range of slides.
- `ppPublishNamedSlideShow` = 3  
  Publish a named slideshow.
