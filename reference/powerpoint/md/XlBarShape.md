# XlBarShape

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the shape used with the 3D bar or column chart.

## Constants (6)

- `xlBox` = 0  
  A box.
- `xlPyramidToPoint` = 1  
  A pyramid, coming to a point at the specified value.
- `xlPyramidToMax` = 2  
  A pyramid, truncated at the specified value.
- `xlCylinder` = 3  
  A cylinder.
- `xlConeToPoint` = 4  
  A cone, coming to a point at the specified value.
- `xlConeToMax` = 5  
  A cone, truncated at the specified value.
