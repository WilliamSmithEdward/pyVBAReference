# PpAdvanceMode

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies how the specified animation advances.

## Constants (3)

- `ppAdvanceModeMixed` = -2  
  Mixed mode.
- `ppAdvanceOnClick` = 1  
  Only when clicked.
- `ppAdvanceOnTime` = 2  
  Automatically after a specified amount of time.
