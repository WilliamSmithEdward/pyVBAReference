# PpAfterEffect

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Indicates whether the specified shape appears dimmed, hidden, or unchanged after it is built.

## Constants (5)

- `ppAfterEffectMixed` = -2  
  Mixed effect
- `ppAfterEffectNothing` = 0  
  No effect
- `ppAfterEffectHide` = 1  
  Hides
- `ppAfterEffectDim` = 2  
  Appears dimmed
- `ppAfterEffectHideOnClick` = 3  
  Hidden when clicked
