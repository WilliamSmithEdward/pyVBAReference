# PpParagraphAlignment

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the alignment for each paragraph in the specified paragraph format.

## Constants (8)

- `ppAlignmentMixed` = -2  
  Mixed alignment
- `ppAlignLeft` = 1  
  Left aligned
- `ppAlignCenter` = 2  
  Center align
- `ppAlignRight` = 3  
  Right-aligned
- `ppAlignJustify` = 4  
  Justify
- `ppAlignDistribute` = 5  
  Distribute
- `ppAlignThaiDistribute` = 6  
  Thai distributed
- `ppAlignJustifyLow` = 7  
  Low justify
