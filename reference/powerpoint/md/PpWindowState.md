# PpWindowState

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the window state, passed to and returned by the WindowState property of the DocumentWindow object.

## Constants (3)

- `ppWindowNormal` = 1  
  Normal
- `ppWindowMinimized` = 2  
  Minimized
- `ppWindowMaximized` = 3  
  Maximized
