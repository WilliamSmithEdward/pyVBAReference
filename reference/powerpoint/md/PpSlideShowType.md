# PpSlideShowType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the type of slide show, passed to and returned by the ShowType property of the SlideShowSettings object.

## Constants (4)

- `ppShowTypeSpeaker` = 1  
  Speaker
- `ppShowTypeWindow` = 2  
  Window
- `ppShowTypeKiosk` = 3  
  Kiosk
- `ppShowTypeWindow2` = 4  
  Window2
