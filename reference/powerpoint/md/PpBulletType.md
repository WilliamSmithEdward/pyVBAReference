# PpBulletType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the type of bullet.

## Constants (5)

- `ppBulletMixed` = -2  
  Mixed bullets
- `ppBulletNone` = 0  
  No bullets
- `ppBulletUnnumbered` = 1  
  Unnumbered bullets
- `ppBulletNumbered` = 2  
  Numbered bullets
- `ppBulletPicture` = 3  
  Bullets with an image
