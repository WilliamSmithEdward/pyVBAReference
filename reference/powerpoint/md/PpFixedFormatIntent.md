# PpFixedFormatIntent

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the intent of the fixed-format file export, passed to the ExportAsFixedFormat method of the Presentation object.

## Constants (2)

- `ppFixedFormatIntentScreen` = 1  
  Intent is to view exported file on screen.
- `ppFixedFormatIntentPrint` = 2  
  Intent is to print exported file.
