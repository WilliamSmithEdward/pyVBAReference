# XlBorderWeight

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the weight of the border around a range.

## Constants (4)

- `xlHairline` = 1  
  A hairline border (thinnest border).
- `xlMedium` = -4138  
  A medium border.
- `xlThick` = 4  
  A thick border (widest border).
- `xlThin` = 2  
  A thin border.
