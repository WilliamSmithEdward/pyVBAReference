# PpHTMLVersion

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the version of HTML for a published presentation.

## Constants (4)

- `ppHTMLv3` = 1  
  HTML Version 3
- `ppHTMLv4` = 2  
  HTML Version 4 (Default)
- `ppHTMLDual` = 3  
  Dual version
- `ppHTMLAutodetect` = 4  
  Autodetect
