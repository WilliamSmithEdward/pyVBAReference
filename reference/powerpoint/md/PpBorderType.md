# PpBorderType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Indicates the direction in which a cell border or diagonal line is drawn.

## Constants (6)

- `ppBorderTop` = 1  
  Top
- `ppBorderLeft` = 2  
  Left
- `ppBorderBottom` = 3  
  Bottom
- `ppBorderRight` = 4  
  Right
- `ppBorderDiagonalDown` = 5  
  Diagonally down
- `ppBorderDiagonalUp` = 6  
  Diagonally up
