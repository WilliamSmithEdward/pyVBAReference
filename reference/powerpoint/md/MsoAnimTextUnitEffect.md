# MsoAnimTextUnitEffect

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies how special effects are applied to the animation for the specified text during a slide show.

## Constants (4)

- `msoAnimTextUnitEffectMixed` = -1  
  Mixed effect.
- `msoAnimTextUnitEffectByParagraph` = 0  
  By paragraph.
- `msoAnimTextUnitEffectByCharacter` = 1  
  By character.
- `msoAnimTextUnitEffectByWord` = 2  
  By word.
