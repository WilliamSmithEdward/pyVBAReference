# PpSelectionType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the type of selection, returned by the Type property of the Selection object.

## Constants (4)

- `ppSelectionNone` = 0  
  None
- `ppSelectionSlides` = 1  
  Slides
- `ppSelectionShapes` = 2  
  Shapes
- `ppSelectionText` = 3  
  Text
