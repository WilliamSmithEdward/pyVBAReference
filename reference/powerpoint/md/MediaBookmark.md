# MediaBookmark

**Type:** Dispatch Interface  
**Library:** Microsoft PowerPoint 16.0 Object Library  
**GUID:** {BA72E555-4FF5-48F4-8215-5505F990966F}  

Contains properties and methods that specify information about the bookmark of the media.

## Properties (3)

- `Index As Long  (read-only)`  
  Returns the index position of the bookmark. Read-only.
- `Name As String  (read-only)`  
  Returns the name of the bookmark. Read-only.
- `Position As Long  (read-only)`  
  Returns the time that is associated with the bookmark. Read-only.

## Methods (1)

- `Delete()`  
  Deletes the bookmark from the collection.
