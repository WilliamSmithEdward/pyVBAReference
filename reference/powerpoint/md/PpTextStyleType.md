# PpTextStyleType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the text style type, passed to the Item method of the TextStyles collection.

## Constants (3)

- `ppDefaultStyle` = 1  
  Default style
- `ppTitleStyle` = 2  
  Title style
- `ppBodyStyle` = 3  
  Body style
