# PpChangeCase

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies the way the case of the specified text will be changed.

## Constants (5)

- `ppCaseSentence` = 1  
  Change to lowercase.
- `ppCaseLower` = 2  
  Change to lowercase.
- `ppCaseUpper` = 3  
  Change to uppercase.
- `ppCaseTitle` = 4  
  Change to title case.
- `ppCaseToggle` = 5  
  Toggle the casing.
