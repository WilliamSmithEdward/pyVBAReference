# PpTabStopType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the tab-stop type, passed to and returned by the Type property of the TabStop object.

## Constants (5)

- `ppTabStopMixed` = -2  
  Mixed
- `ppTabStopLeft` = 1  
  Left tab stop
- `ppTabStopCenter` = 2  
  Center tab stop
- `ppTabStopRight` = 3  
  Right tab stop
- `ppTabStopDecimal` = 4  
  Decimal tab stop
