# PpSlideShowAdvanceMode

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the mode of advance of the slide show, passed to and returned by the AdvanceMode property of the SlideShowSettings object.

## Constants (3)

- `ppSlideShowManualAdvance` = 1  
  Manual Advance
- `ppSlideShowUseSlideTimings` = 2  
  Specified timings for each slide
- `ppSlideShowRehearseNewTimings` = 3  
  Rehearsed timings
