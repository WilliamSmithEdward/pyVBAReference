# MsoAnimEffectRestart

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Specifies whether the animation effect restarts after the effect has started once.

## Constants (3)

- `msoAnimEffectRestartAlways` = 1  
  Always restarts.
- `msoAnimEffectRestartWhenOff` = 2  
  Restarts when animation is off.
- `msoAnimEffectRestartNever` = 3  
  Never restarts.
