# MsoAnimCommandType

**Type:** Enumeration  
**Library:** Microsoft PowerPoint 16.0 Object Library  

Constants that specify the type of the animation command, passed to and returned by the Type property of the CommandEffect object.

## Constants (3)

- `msoAnimCommandTypeEvent` = 0  
  Event
- `msoAnimCommandTypeCall` = 1  
  Call
- `msoAnimCommandTypeVerb` = 2  
  Verb
