# WdNumberingRule

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the numbering rule to apply.

## Constants (3)

- `wdRestartContinuous` = 0  
  Numbers are assigned continuously.
- `wdRestartSection` = 1  
  Numbers are reset for each section.
- `wdRestartPage` = 2  
  Numbers are reset for each page.
