# WdIndexSortBy

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the criteria by which Word sorts the specified index.

## Constants (2)

- `wdIndexSortByStroke` = 0  
  Sort by the number of strokes in a character.
- `wdIndexSortBySyllable` = 1  
  Sort phonetically.
