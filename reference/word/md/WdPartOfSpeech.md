# WdPartOfSpeech

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the part of speech that a word represents when returned by the Word thesaurus service.

## Constants (10)

- `wdAdjective` = 0  
  An adjective.
- `wdNoun` = 1  
  A noun.
- `wdAdverb` = 2  
  An adverb.
- `wdVerb` = 3  
  A verb.
- `wdPronoun` = 4  
  A pronoun.
- `wdConjunction` = 5  
  A conjunction.
- `wdPreposition` = 6  
  A preposition.
- `wdInterjection` = 7  
  An interjection.
- `wdIdiom` = 8  
  An idiom.
- `wdOther` = 9  
  Some other part of speech.
