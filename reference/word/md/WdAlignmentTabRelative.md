# WdAlignmentTabRelative

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies whether Microsoft Word calculates the alignment for a tab relative to the section margins or the paragraph indents.

## Constants (2)

- `wdMargin` = 0  
  Word calculates tab alignment relative to the margins
- `wdIndent` = 1  
  Word calculates tab alignment relative to the paragraph indents.
