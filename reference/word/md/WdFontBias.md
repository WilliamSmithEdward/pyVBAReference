# WdFontBias

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the font bias for symbols.

## Constants (3)

- `wdFontBiasDontCare` = 255  
  No font bias specified.
- `wdFontBiasDefault` = 0  
  Default font bias.
- `wdFontBiasFareast` = 1  
  Font bias for Asian languages.
