# WdSortSeparator

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of field separator.

## Constants (3)

- `wdSortSeparateByTabs` = 0  
  Tab.
- `wdSortSeparateByCommas` = 1  
  Comma.
- `wdSortSeparateByDefaultTableSeparator` = 2  
  Default table separator.
