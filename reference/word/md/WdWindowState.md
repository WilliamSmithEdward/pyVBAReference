# WdWindowState

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the state of the current document window or task window.

## Constants (3)

- `wdWindowStateNormal` = 0  
  Normal.
- `wdWindowStateMaximize` = 1  
  Maximized.
- `wdWindowStateMinimize` = 2  
  Minimized.
