# WdMailMergeMailFormat

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the format to use when the mail merge destination is an email message.

## Constants (2)

- `wdMailFormatPlainText` = 0  
  Sends mail merge email documents using plain text.
- `wdMailFormatHTML` = 1  
  Sends mail merge email documents using HTML format.
