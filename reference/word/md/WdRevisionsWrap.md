# WdRevisionsWrap

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies how revision marks are displayed in the document.

## Constants (3)

- `wdWrapNever` = 0  
  Never wrap revisions.
- `wdWrapAlways` = 1  
  Revisions are wrapped.
- `wdWrapAsk` = 2  
  Ask the user if revisions should be wrapped.
