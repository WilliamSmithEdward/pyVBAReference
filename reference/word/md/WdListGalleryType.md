# WdListGalleryType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of list from a list template gallery.

## Constants (3)

- `wdBulletGallery` = 1  
  Bulleted list.
- `wdNumberGallery` = 2  
  Numbered list.
- `wdOutlineNumberGallery` = 3  
  Outline numbered list.
