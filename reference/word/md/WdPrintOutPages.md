# WdPrintOutPages

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of pages to print.

## Constants (3)

- `wdPrintAllPages` = 0  
  All pages.
- `wdPrintOddPagesOnly` = 1  
  Odd-numbered pages only.
- `wdPrintEvenPagesOnly` = 2  
  Even-numbered pages only.
