# WdFarEastLineBreakLanguageID

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the East Asian language to use when breaking lines of text in the specified document or template.

## Constants (4)

- `wdLineBreakJapanese` = 1041  
  Japanese.
- `wdLineBreakKorean` = 1042  
  Korean.
- `wdLineBreakSimplifiedChinese` = 2052  
  Simplified Chinese.
- `wdLineBreakTraditionalChinese` = 1028  
  Traditional Chinese.
