# WdTabAlignment

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the tab stop alignment to apply.

## Constants (6)

- `wdAlignTabLeft` = 0  
  Left-aligned.
- `wdAlignTabCenter` = 1  
  Center-aligned.
- `wdAlignTabRight` = 2  
  Right-aligned.
- `wdAlignTabDecimal` = 3  
  Decimal-aligned.
- `wdAlignTabBar` = 4  
  Bar-aligned.
- `wdAlignTabList` = 6  
  List-aligned.
