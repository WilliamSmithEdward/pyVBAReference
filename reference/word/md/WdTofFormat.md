# WdTofFormat

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of formatting to apply to the table of figures in the active document.

## Constants (6)

- `wdTOFTemplate` = 0  
  Template formatting.
- `wdTOFClassic` = 1  
  Classic formatting.
- `wdTOFDistinctive` = 2  
  Distinctive formatting.
- `wdTOFCentered` = 3  
  Centered formatting.
- `wdTOFFormal` = 4  
  Formal formatting.
- `wdTOFSimple` = 5  
  Simple formatting.
