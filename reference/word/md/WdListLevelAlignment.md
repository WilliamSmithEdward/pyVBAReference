# WdListLevelAlignment

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the alignment of a list level.

## Constants (3)

- `wdListLevelAlignLeft` = 0  
  Left-aligned.
- `wdListLevelAlignCenter` = 1  
  Center-aligned.
- `wdListLevelAlignRight` = 2  
  Right-aligned.
