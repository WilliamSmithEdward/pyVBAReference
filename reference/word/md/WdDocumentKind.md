# WdDocumentKind

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the format type that Microsoft Word uses when automatically formatting a document.

## Constants (3)

- `wdDocumentNotSpecified` = 0  
  No format specified.
- `wdDocumentLetter` = 1  
  Letter format.
- `wdDocumentEmail` = 2  
  Email format.
