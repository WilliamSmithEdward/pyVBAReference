# WdFlowDirection

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the direction in which text flows from one text column to the next.

## Constants (2)

- `wdFlowLtr` = 0  
  Text in columns flows from left to right.
- `wdFlowRtl` = 1  
  Text in columns flows from right to left.
