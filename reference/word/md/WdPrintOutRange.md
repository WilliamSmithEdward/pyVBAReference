# WdPrintOutRange

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies a range to print.

## Constants (5)

- `wdPrintAllDocument` = 0  
  The entire document.
- `wdPrintSelection` = 1  
  The current selection.
- `wdPrintCurrentPage` = 2  
  The current page.
- `wdPrintFromTo` = 3  
  A specified range.
- `wdPrintRangeOfPages` = 4  
  A specified range of pages.
