# WdSelectionType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of selection.

## Constants (9)

- `wdNoSelection` = 0  
  No selection.
- `wdSelectionIP` = 1  
  An inline paragraph selection.
- `wdSelectionNormal` = 2  
  A normal or user-defined selection.
- `wdSelectionFrame` = 3  
  A frame selection.
- `wdSelectionColumn` = 4  
  A column selection.
- `wdSelectionRow` = 5  
  A row selection.
- `wdSelectionBlock` = 6  
  A block selection.
- `wdSelectionInlineShape` = 7  
  An inline shape selection.
- `wdSelectionShape` = 8  
  A shape selection.
