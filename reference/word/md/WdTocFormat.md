# WdTocFormat

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of formatting to apply to the table of contents in the active document.

## Constants (7)

- `wdTOCTemplate` = 0  
  Template formatting.
- `wdTOCClassic` = 1  
  Classic formatting.
- `wdTOCDistinctive` = 2  
  Distinctive formatting.
- `wdTOCFancy` = 3  
  Fancy formatting.
- `wdTOCModern` = 4  
  Modern formatting.
- `wdTOCFormal` = 5  
  Formal formatting.
- `wdTOCSimple` = 6  
  Simple formatting.
