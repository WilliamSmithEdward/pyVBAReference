# WdEnclosureType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of symbol to use as an enclosure.

## Constants (4)

- `wdEnclosureCircle` = 0  
  A circle.
- `wdEnclosureSquare` = 1  
  A square.
- `wdEnclosureTriangle` = 2  
  A triangle.
- `wdEnclosureDiamond` = 3  
  A diamond.
