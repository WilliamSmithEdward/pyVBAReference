# WdSalutationType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of salutation to use for a letter.

## Constants (4)

- `wdSalutationInformal` = 0  
  Informal salutation.
- `wdSalutationFormal` = 1  
  Format salutation.
- `wdSalutationBusiness` = 2  
  Business salutation
- `wdSalutationOther` = 3  
  Custom salutation.
