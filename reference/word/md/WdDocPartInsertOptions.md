# WdDocPartInsertOptions

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies how a building block is inserted into a document.

## Constants (3)

- `wdInsertContent` = 0  
  Inline building block.
- `wdInsertParagraph` = 1  
  Paragraph-level building block.
- `wdInsertPage` = 2  
  Page-level building block.
