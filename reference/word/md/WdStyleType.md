# WdStyleType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the style type to apply.

## Constants (6)

- `wdStyleTypeParagraph` = 1  
  Paragraph style.
- `wdStyleTypeCharacter` = 2  
  Body character style.
- `wdStyleTypeTable` = 3  
  Table style.
- `wdStyleTypeList` = 4  
  List style.
- `wdStyleTypeParagraphOnly` = 5
- `wdStyleTypeLinked` = 6
