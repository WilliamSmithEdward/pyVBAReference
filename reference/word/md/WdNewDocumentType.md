# WdNewDocumentType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of new document to create.

## Constants (5)

- `wdNewBlankDocument` = 0  
  Blank document.
- `wdNewWebPage` = 1  
  Web page.
- `wdNewEmailMessage` = 2  
  Email message.
- `wdNewFrameset` = 3  
  Frameset.
- `wdNewXMLDocument` = 4  
  XML document.
