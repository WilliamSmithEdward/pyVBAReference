# XlErrorBarDirection

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies which axis values are to receive error bars.

## Constants (2)

- `xlChartX` = -4168  
  Bars run parallel to the y-axis for x-axis values.
- `xlChartY` = 1  
  Bars run parallel to the x-axis for y-axis values.
