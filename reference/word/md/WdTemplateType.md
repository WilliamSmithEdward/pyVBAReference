# WdTemplateType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of template.

## Constants (3)

- `wdNormalTemplate` = 0  
  The normal default template.
- `wdGlobalTemplate` = 1  
  A global template.
- `wdAttachedTemplate` = 2  
  An attached template.
