# WdMonthNames

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the format in which to display month names.

## Constants (3)

- `wdMonthNamesArabic` = 0  
  Arabic format.
- `wdMonthNamesEnglish` = 1  
  English format.
- `wdMonthNamesFrench` = 2  
  French format.
