# WdOMathHorizAlignType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the horizontal alignment for an equation.

## Constants (3)

- `wdOMathHorizAlignCenter` = 0  
  Centered.
- `wdOMathHorizAlignLeft` = 1  
  Left alignment.
- `wdOMathHorizAlignRight` = 2  
  Right alignment.
