# WdCollapseDirection

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the direction in which to collapse a range or selection.

## Constants (2)

- `wdCollapseStart` = 1  
  Collapse the range to the starting point.
- `wdCollapseEnd` = 0  
  Collapse the range to the ending point.
