# WdSpellingErrorType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies a spelling error type.

## Constants (3)

- `wdSpellingCorrect` = 0  
  Spelling is correct.
- `wdSpellingNotInDictionary` = 1  
  The word is not in the specified dictionary.
- `wdSpellingCapitalization` = 2  
  Capitalization error.
