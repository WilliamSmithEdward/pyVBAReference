# WdMeasurementUnits

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies a unit of measure to use.

## Constants (5)

- `wdInches` = 0  
  Inches.
- `wdCentimeters` = 1  
  Centimeters.
- `wdMillimeters` = 2  
  Millimeters.
- `wdPoints` = 3  
  Points.
- `wdPicas` = 4  
  Picas (commonly used in traditional typewriter font spacing).
