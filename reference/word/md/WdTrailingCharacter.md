# WdTrailingCharacter

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the character inserted after the number for a numbered list item.

## Constants (3)

- `wdTrailingTab` = 0  
  A tab is inserted.
- `wdTrailingSpace` = 1  
  A space is inserted. Default.
- `wdTrailingNone` = 2  
  No character is inserted.
