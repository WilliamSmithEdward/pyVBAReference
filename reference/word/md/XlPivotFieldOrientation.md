# XlPivotFieldOrientation

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the location of the field in a PivotTable report.

## Constants (5)

- `xlColumnField` = 2  
  A column field.
- `xlDataField` = 4  
  A data field.
- `xlHidden` = 0  
  A hidden field.
- `xlPageField` = 3  
  A page field.
- `xlRowField` = 1  
  A row field.
