# WdSpellingWordType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the way Microsoft Word makes spelling suggestions.

## Constants (3)

- `wdSpellword` = 0  
  Spellword searching.
- `wdWildcard` = 1  
  Wildcard searching.
- `wdAnagram` = 2  
  Anagram searching.
