# WdSeparatorType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of separator to place between items.

## Constants (5)

- `wdSeparatorHyphen` = 0  
  A hyphen.
- `wdSeparatorPeriod` = 1  
  A period.
- `wdSeparatorColon` = 2  
  A colon.
- `wdSeparatorEmDash` = 3  
  An emphasized dash.
- `wdSeparatorEnDash` = 4  
  A standard dash.
