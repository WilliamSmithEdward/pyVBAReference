# WdReferenceType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of item to be cross referenced.

## Constants (5)

- `wdRefTypeNumberedItem` = 0  
  Numbered item.
- `wdRefTypeHeading` = 1  
  Heading.
- `wdRefTypeBookmark` = 2  
  Bookmark.
- `wdRefTypeFootnote` = 3  
  Footnote.
- `wdRefTypeEndnote` = 4  
  Endnote.
