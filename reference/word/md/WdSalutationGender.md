# WdSalutationGender

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the gender to use in a salutation.

## Constants (4)

- `wdGenderFemale` = 0  
  Female gender.
- `wdGenderMale` = 1  
  Male gender.
- `wdGenderNeutral` = 2  
  Neutral gender.
- `wdGenderUnknown` = 3  
  Unknown gender.
