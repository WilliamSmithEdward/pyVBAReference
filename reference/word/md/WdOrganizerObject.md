# WdOrganizerObject

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of object used by a delete, copy, or rename action.

## Constants (4)

- `wdOrganizerObjectStyles` = 0  
  A style item.
- `wdOrganizerObjectAutoText` = 1  
  An AutoText item.
- `wdOrganizerObjectCommandBars` = 2  
  A command bar item.
- `wdOrganizerObjectProjectItems` = 3  
  A project item.
