# WdToaFormat

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of formatting to apply to the table of authorities in the active document.

## Constants (5)

- `wdTOATemplate` = 0  
  Template formatting.
- `wdTOAClassic` = 1  
  Classic formatting.
- `wdTOADistinctive` = 2  
  Distinctive formatting.
- `wdTOAFormal` = 3  
  Formal formatting.
- `wdTOASimple` = 4  
  Simple formatting.
