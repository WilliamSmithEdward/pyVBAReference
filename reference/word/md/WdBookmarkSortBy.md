# WdBookmarkSortBy

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the sorting option for bookmark names displayed in the Bookmark dialog box.

## Constants (2)

- `wdSortByName` = 0  
  Sorted by bookmark name.
- `wdSortByLocation` = 1  
  Sorted by location in document.
