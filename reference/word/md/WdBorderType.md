# WdBorderType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of border to be used.

## Constants (8)

- `wdBorderTop` = -1  
  A top border.
- `wdBorderLeft` = -2  
  A left border.
- `wdBorderBottom` = -3  
  A bottom border.
- `wdBorderRight` = -4  
  A right border.
- `wdBorderHorizontal` = -5  
  Horizontal borders.
- `wdBorderVertical` = -6  
  Vertical borders.
- `wdBorderDiagonalDown` = -7  
  A diagonal border starting in the upper-left corner.
- `wdBorderDiagonalUp` = -8  
  A diagonal border starting in the lower-left corner.
