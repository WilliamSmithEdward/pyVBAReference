# WdCheckInVersionType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of version for the document checked in when using the CheckIn method. Applies to documents stored in a SharePoint library.

## Constants (3)

- `wdCheckInMinorVersion` = 0  
  Minor version.
- `wdCheckInMajorVersion` = 1  
  Major version.
- `wdCheckInOverwriteVersion` = 2  
  Overwrite current version on the server.
