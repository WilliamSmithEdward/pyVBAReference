# WdOMathFracType

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies the type of fraction bar.

## Constants (4)

- `wdOMathFracBar` = 0  
  Normal fraction bar.
- `wdOMathFracNoBar` = 1  
  No fraction bar.
- `wdOMathFracSkw` = 2  
  Skewed fraction bar.
- `wdOMathFracLin` = 3  
  Show fraction inline.
