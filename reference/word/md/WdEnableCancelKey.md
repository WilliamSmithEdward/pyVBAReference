# WdEnableCancelKey

**Type:** Enumeration  
**Library:** Microsoft Word 16.0 Object Library  

Specifies whether CTRL+BREAK can or cannot interrupt a macro

## Constants (2)

- `wdCancelDisabled` = 0  
  Prevents CTRL+BREAK from interrupting a macro.
- `wdCancelInterrupt` = 1  
  Allows a macro to be interrupted by CTRL+BREAK.
