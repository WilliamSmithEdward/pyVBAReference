# MsoSmartArtNodePosition

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies constants that define the different ways to add a new node to the data model in SmartArt.

## Constants (5)

- `msoSmartArtNodeDefault` = 1  
  The default. Corresponds to clicking Add Shape in the SmartArt ribbon.
- `msoSmartArtNodeAfter` = 2  
  Insert a node after the SmartArt node in the data model. Corresponds to clicking Add Shape After in the SmartArt ribbon.
- `msoSmartArtNodeBefore` = 3  
  Insert a node before the SmartArt node in the data model.
- `msoSmartArtNodeAbove` = 4  
  Insert a node above the SmartArt node in the data model.
- `msoSmartArtNodeBelow` = 5  
  Insert a node below the SmartArt node in the data model.
