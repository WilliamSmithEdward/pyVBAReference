# MsoFileNewAction

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the action to take when a user clicks an item in the task pane. Used with the Add method of the NewFile object.

## Constants (3)

- `msoEditFile` = 0  
  Edit a file.
- `msoCreateNewFile` = 1  
  Create a new file.
- `msoOpenFile` = 2  
  Open a file.
