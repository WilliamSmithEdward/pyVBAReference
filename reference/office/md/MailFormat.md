# MailFormat

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies how the body of the email is displayed.

## Constants (3)

- `mfPlainText` = 1  
  The email is displayed as plain text.
- `mfHTML` = 2  
  The email is displayed as HyperText Markup Language (HTML).
- `mfRTF` = 3  
  The email is displayed as Rich Text Format (RTF).
