# MsoSyncEventType

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the return value of a Sync event. In Microsoft Word, used with the Sync event of the Document object or the DocumentSync event of the Application object. In Microsoft Excel, used with the Sync event of the Workbook object or the WorkbookSync event of the Application object. In Microsoft PowerPoint, used with the PresentationSync event of the Application object.

## Constants (8)

- `msoSyncEventDownloadInitiated` = 0  
  Download initiated.
- `msoSyncEventDownloadSucceeded` = 1  
  Download succeeded.
- `msoSyncEventDownloadFailed` = 2  
  Download failed.
- `msoSyncEventUploadInitiated` = 3  
  Upload initiated.
- `msoSyncEventUploadSucceeded` = 4  
  Upload succeeded.
- `msoSyncEventUploadFailed` = 5  
  Upload failed.
- `msoSyncEventDownloadNoChange` = 6  
  No change detected.
- `msoSyncEventOffline` = 7  
  Offline.
