# MsoZOrderCmd

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies where in the z-order a shape should be moved relative to other shapes.

## Constants (6)

- `msoBringToFront` = 0  
  Bring shape to the front.
- `msoSendToBack` = 1  
  Send shape to the back.
- `msoBringForward` = 2  
  Bring shape forward.
- `msoSendBackward` = 3  
  Send shape backward.
- `msoBringInFrontOfText` = 4  
  Bring shape in front of text. Used only in Microsoft Word.
- `msoSendBehindText` = 5  
  Send shape behind text. Used only in Microsoft Word.
