# XlSizeRepresents

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Indicates what the size measurement is in relation to (area or width).

## Constants (2)

- `xlSizeIsWidth` = 2  
  The size measure is for the width.
- `xlSizeIsArea` = 1  
  The size measure is for the area.
