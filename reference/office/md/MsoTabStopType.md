# MsoTabStopType

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the type of tab stop.

## Constants (5)

- `msoTabStopMixed` = -2  
  Return value only; indicates a combination of the other states.
- `msoTabStopLeft` = 1  
  Left tab stop
- `msoTabStopCenter` = 2  
  Center tab stop
- `msoTabStopRight` = 3  
  Right tab stop
- `msoTabStopDecimal` = 4  
  Decimal tab stop
