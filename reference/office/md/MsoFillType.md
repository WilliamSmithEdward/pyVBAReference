# MsoFillType

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies a shape's fill type.

## Constants (7)

- `msoFillMixed` = -2  
  Mixed fill
- `msoFillSolid` = 1  
  Solid fill
- `msoFillPatterned` = 2  
  Patterned fill
- `msoFillGradient` = 3  
  Gradient fill
- `msoFillTextured` = 4  
  Textured fill
- `msoFillBackground` = 5  
  Fill is the same as the background.
- `msoFillPicture` = 6  
  Picture fill
