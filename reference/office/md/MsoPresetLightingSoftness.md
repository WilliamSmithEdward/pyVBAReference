# MsoPresetLightingSoftness

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the intensity of light used on a shape.

## Constants (4)

- `msoPresetLightingSoftnessMixed` = -2  
  Not supported
- `msoLightingDim` = 1  
  Dim light
- `msoLightingNormal` = 2  
  Normal light
- `msoLightingBright` = 3  
  Bright light
