# MsoSmartArtNodeType

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies constants that define the types of SmartArt nodes.

## Constants (2)

- `msoSmartArtNodeTypeDefault` = 1  
  The default node type.
- `msoSmartArtNodeTypeAssistant` = 2  
  Defines an assistant node, which can be used within hierarchical diagrams.
