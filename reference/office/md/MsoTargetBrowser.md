# MsoTargetBrowser

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies target browser for documents viewed in a web browser.

## Constants (5)

- `msoTargetBrowserV3` = 0  
  Microsoft Internet Explorer 3.0, Netscape Navigator 3, or later
- `msoTargetBrowserV4` = 1  
  Microsoft Internet Explorer 4.0, Netscape Navigator 4, or later
- `msoTargetBrowserIE4` = 2  
  Microsoft Internet Explorer 4.0 or later
- `msoTargetBrowserIE5` = 3  
  Microsoft Internet Explorer 5 or later
- `msoTargetBrowserIE6` = 4  
  Microsoft Internet Explorer 6 or later
