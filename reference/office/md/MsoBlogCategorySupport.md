# MsoBlogCategorySupport

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies how many categories are supported by the provider.

## Constants (3)

- `msoBlogNoCategories` = 0  
  No categories are supported.
- `msoBlogOneCategory` = 1  
  One category is supported.
- `msoBlogMultipleCategories` = 2  
  Multiple categories are supported.
