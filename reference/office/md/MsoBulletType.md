# MsoBulletType

**Type:** Enumeration  
**Library:** Microsoft Office 16.0 Object Library  

Specifies the bullet type.

## Constants (5)

- `msoBulletMixed` = -2  
  Return value only; indicates a combination of the other states.
- `msoBulletNone` = 0  
  No bullets.
- `msoBulletUnnumbered` = 1  
  Unnumbered bullets.
- `msoBulletNumbered` = 2  
  Numbered bullets.
- `msoBulletPicture` = 3  
  Picture bullets.
