# AcPrintDuplex

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the Duplex property to specify how the printer handles duplex printing.

## Constants (3)

- `acPRDPSimplex` = 1  
  Single-sided printing with the current orientation setting.
- `acPRDPHorizontal` = 2  
  Double-sided printing using a horizontal page turn.
- `acPRDPVertical` = 3  
  Double-sided printing using a vertical page turn.
