# AcDataLabelDisplayFormat

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the data label format for Pie, Arc, and Doughnut Modern Charts.

## Constants (3)

- `acDataLabelDisplayNone` = 0  
  No Labels
- `acDataLabelDisplayNumber` = 1  
  Labels as Number
- `acDataLabelDisplayPercentage` = 2  
  Labels as Percentage
