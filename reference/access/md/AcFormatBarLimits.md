# AcFormatBarLimits

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies how the threshold values for a Data Bar is determined.

## Constants (3)

- `acAutomatic` = 0  
  For the shortest bar, the lowest value is used. For the highest bar, the highest value is used.
- `acNumber` = 1  
  A number is used.
- `acPercent` = 2  
  A percentage is used.
