# AcShowToolbar

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the DoCmd.ShowToolbar method (Access) method to specify whether to display a particular custom toolbar.

## Constants (3)

- `acToolbarYes` = 0  
  Display the toolbar.
- `acToolbarWhereApprop` = 1  
  Display the toolbar while in the appropriate view.
- `acToolbarNo` = 2  
  Hide the toolbar.
