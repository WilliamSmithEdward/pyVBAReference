# AcCursorOnHover

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the CursorOnHover property to specify the type of cursor displayed when a user rests the pointer on a button.

## Constants (2)

- `acCursorOnHoverDefault` = 0  
  The default cursor is displayed.
- `acCursorOnHoverHyperlinkHand` = 1  
  The hyperlink hand cursor is displayed.
