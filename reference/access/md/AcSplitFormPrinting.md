# AcSplitFormPrinting

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the SplitFormPrinting property to specify what to print when a form is in Split Form view.

## Constants (2)

- `acFormOnly` = 0  
  The contents of the form are printed.
- `acGridOnly` = 1  
  The contents of the datasheet are printed.
