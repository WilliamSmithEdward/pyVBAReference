# AcSearchDirection

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the DoCmd.FindRecord method (Access) method to specify the direction to search.

## Constants (3)

- `acUp` = 0  
  Search all records above the current record.
- `acDown` = 1  
  Search all records below the current record.
- `acSearchAll` = 2  
  Search all records.
