# AcSplitFormDatasheet

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the Form.SplitFormDatasheet property (Access) property to specify whether the user can edit contents of the datasheet while a form is displayed in Split Form view.

## Constants (2)

- `acDatasheetAllowEdits` = 0  
  The user can edit the contents of the datasheet.
- `acDatasheetReadOnly` = 1  
  The user cannot edit the contents of the datasheet.
