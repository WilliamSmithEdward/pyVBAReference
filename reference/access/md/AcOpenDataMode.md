# AcOpenDataMode

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the data entry mode when opening a table, query, stored procedure, view, or user-defined function.

## Constants (3)

- `acAdd` = 0  
  The user can add new records but can't view or edit existing records.
- `acEdit` = 1  
  The user can view or edit existing records and add new records.
- `acReadOnly` = 2  
  The user can only view records.
