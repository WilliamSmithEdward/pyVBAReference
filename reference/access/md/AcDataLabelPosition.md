# AcDataLabelPosition

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the data label position to use for for Pie, Arc, and Doughnut Modern Charts.

## Constants (5)

- `acBestFit` = 0  
  Best Fit
- `acInsideCenter` = 1  
  Inside Center
- `acInsideEnd` = 2  
  Inside End
- `acOutsideCircle` = 3  
  Outside Circle
- `acOutsideEnd` = 4  
  Outside End
