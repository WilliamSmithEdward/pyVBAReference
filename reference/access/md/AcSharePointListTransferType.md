# AcSharePointListTransferType

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the DoCmd.TransferSharePointList method (Access) method to specify whether to import or link to a SharePoint list.

## Constants (2)

- `acImportSharePointList` = 0  
  Import the SharePoint list.
- `acLinkSharePointList` = 1  
  Link to the SharePoint list.
