# Operations

**Type:** Dispatch Interface  
**Library:** Microsoft Access 16.0 Object Library  
**GUID:** {CB2DF2B1-383D-4A3E-BBA1-B0E6D1CC48AC}  

Represents the collection of operations defined for an Entity object.

**Remarks:** Use the Operations property of the Entity object to return the collection of operations for an entity.

## Properties (3)

- `Parent As Object  (read-only)`  
  Returns the parent object for the specified object. Read-only.
- `Item As Operation  (read-only)`  
  The Item property returns a specific member of a collection either by position or by index. Read-only Object.
- `Count As Long  (read-only)`  
  Use the Count property to determine the number of items in a specified collection. Read-only Long.
