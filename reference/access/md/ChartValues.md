# ChartValues

**Type:** Class  
**Library:** Microsoft Access 16.0 Object Library  
**GUID:** {47F87268-B60C-4C6D-8C71-230D96996A69}  

Represents a field whose values will be plotted in the value (Y) axis of a chart.

## Properties (2)

- `Name As String  (read-only)`  
  Returns the name of a ChartValues instance based on its associated field. Read-only String.
- `AggregateType As AcAggregateType  (read/write)`  
  Returns or sets the behavior for aggregating values. Read/write AcAggregateType.
