# ChartAxis

**Type:** Class  
**Library:** Microsoft Access 16.0 Object Library  
**GUID:** {A51D694D-3497-45B8-BAD9-FAF47556BCCF}  

Represents a field whose values will be included in the category axis of a chart.

## Properties (2)

- `Name As String  (read-only)`  
  Returns the name of a ChartAxis instance based on its associated field. Read-only String.
- `GroupType As AcDateGroupType  (read/write)`  
  Returns or sets the type of grouping applied to an axis field when its type is a date. Read/write AcDateGroupType.
