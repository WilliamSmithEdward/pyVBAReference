# AcTrendlineOptions

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the type of trendline to render for a chart series.

## Constants (7)

- `acTrendlineNone` = 0  
  None
- `acTrendlineLinear` = 1  
  Linear
- `acTrendlineExponential` = 2  
  Exponential
- `acTrendlineLogarithmic` = 3  
  Logarithmic
- `acTrendlinePolynomial` = 4  
  Polynomial
- `acTrendlinePower` = 5  
  Power
- `acTrendlineMovingAverage` = 6  
  Moving Average
