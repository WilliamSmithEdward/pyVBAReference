# AcSortOrderType

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the sort order type for series in a Modern Chart.

## Constants (3)

- `acSortOrderTypeNone` = 0  
  None
- `acSortOrderTypeAscending` = 1  
  Ascending
- `acSortOrderTypeDescending` = 2  
  Descending
