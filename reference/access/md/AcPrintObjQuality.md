# AcPrintObjQuality

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the PrintQuality property to specify the resolution at which the specified printer should print jobs.

## Constants (4)

- `acPRPQDraft` = -1  
  The printer prints in draft quality.
- `acPRPQLow` = -2  
  The printer prints in low quality.
- `acPRPQMedium` = -3  
  The printer prints in medium quality.
- `acPRPQHigh` = -4  
  The printer prints in high quality.
