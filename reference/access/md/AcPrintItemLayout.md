# AcPrintItemLayout

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the ItemLayout property to specify how columns are laid out when printing.

## Constants (2)

- `acPRHorizontalColumnLayout` = 1953  
  Columns are laid across, then down.
- `acPRVerticalColumnLayout` = 1954  
  Columns are laid down, then across.
