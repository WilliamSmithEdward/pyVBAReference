# AcProjectType

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the ProjectType property to determine the type of project that is currently open.

## Constants (3)

- `acNull` = 0
- `acADP` = 1  
  The current project is a Microsoft Access project.
- `acMDB` = 2  
  The current project is a Microsoft Access database.
