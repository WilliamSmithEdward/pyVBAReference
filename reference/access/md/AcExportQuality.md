# AcExportQuality

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Use with the OutputTo method to specify the type of output device to optimize for when exporting an object.

## Constants (2)

- `acExportQualityPrint` = 0  
  The output is optimized for printing.
- `acExportQualityScreen` = 1  
  The output is optimized for onscreen display.
