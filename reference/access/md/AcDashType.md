# AcDashType

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the line dash style for a series when its effective chart type is line-based.

## Constants (5)

- `acDashTypeSolid` = 0  
  Solid
- `acDashTypeDash` = 1  
  Dash
- `acDashTypeDot` = 2  
  Dot
- `acDashTypeDashDot` = 3  
  Dash Dot
- `acDashTypeDashDotDot` = 4
