# AcTransformXMLScriptOption

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the TransformXML method to specify the action taken if the XSL file contains scripting code.

## Constants (3)

- `acEnableScript` = 0  
  The script is enabled.
- `acPromptScript` = 1  
  The user is prompted to disable or enable the script.
- `acDisableScript` = 2  
  The script is disabled.
