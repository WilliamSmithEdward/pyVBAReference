# AcSendObjectType

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the DoCmd.SendObject method (Access) method to specify the type of object to send.

## Constants (6)

- `acSendNoObject` = -1  
  (Default) Don't send a database object.
- `acSendTable` = 0  
  Send a Table.
- `acSendQuery` = 1  
  Send a Query.
- `acSendForm` = 2  
  Send a Form.
- `acSendReport` = 3  
  Send a Report.
- `acSendModule` = 5  
  Send a Module.
