# AcWebBrowserScrollBars

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used by the ScrollBars property to specify whether scroll bars are displayed.

## Constants (3)

- `acScrollAuto` = 0  
  Scroll bars are displayed if the current page in the control is too large to be displayed in its entirely.
- `acScrollYes` = 1  
  Scroll bars are displayed.
- `acScrollNo` = 2  
  Scroll bars are not displayed.
