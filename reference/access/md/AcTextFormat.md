# AcTextFormat

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the TextFormat property to specify whether or not rich text is displayed in a Text Box.

## Constants (2)

- `acTextFormatPlain` = 0  
  (Default) Plain text is displayed.
- `acTextFormatHTMLRichText` = 1  
  Rich text can be displayed.
