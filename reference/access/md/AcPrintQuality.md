# AcPrintQuality

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the PrintOut method to specify the print quality of a particular print job.

## Constants (4)

- `acHigh` = 0  
  (Default) High quality
- `acMedium` = 1  
  Medium quality
- `acLow` = 2  
  Low quality
- `acDraft` = 3  
  Draft quality
