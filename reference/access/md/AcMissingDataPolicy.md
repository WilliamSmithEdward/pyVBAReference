# AcMissingDataPolicy

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the plotting strategy of a series when its chart type is acChartLine and values are missing.

## Constants (3)

- `acPlotAsZero` = 0  
  Plot as zero.
- `acDoNotPlot` = 1  
  Do not plot.
- `acPlotAsInterpolated` = 2  
  Plot as interpolated.
