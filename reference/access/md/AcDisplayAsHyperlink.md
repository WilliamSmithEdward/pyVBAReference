# AcDisplayAsHyperlink

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Used with the DisplayAsHyperlink property to specify whether to display the contents of a text box or combo box as a hyperlink.

## Constants (3)

- `acDisplayAsHyperlinkIfHyperlink` = 0
- `acDisplayAsHyperlinkAlways` = 1  
  Always display the contents of the control as a hyperlink.
- `acDisplayAsHyperlinkOnScreenOnly` = 2  
  Display the contents of the control as a hyperlink only on the screen.
