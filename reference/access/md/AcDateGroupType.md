# AcDateGroupType

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Specifies the type of grouping applied to an axis; the type of its associated field is a date.

## Constants (5)

- `acDateGroupNone` = 0  
  No grouping is applied.
- `acDateGroupYear` = 1  
  The date is grouped by year.
- `acDateGroupQuarter` = 2  
  The date is grouped by quarter.
- `acDateGroupMonth` = 3  
  The date is grouped by month.
- `acDateGroupDay` = 4  
  The date is grouped by day.
