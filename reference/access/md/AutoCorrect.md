# AutoCorrect

**Type:** Class  
**Library:** Microsoft Access 16.0 Object Library  
**GUID:** {4375351E-7052-40DF-B4D3-6095E7F8811B}  

The AutoCorrect object represents the AutoCorrect functionality of Microsoft Access.

**Remarks:** To return an AutoCorrect object, use the AutoCorrect property. To enable or disable the display of the AutoCorrect Options button, use the DisplayAutoCorrectOptions property. To enable or disable AutoCorrect functionality for a particular TextBox or ComboBox object, use the AllowAutoCorrect property.

## Properties (1)

- `DisplayAutoCorrectOptions As Boolean  (read/write)`  
  Returns or sets a Boolean value that specifies whether the AutoCorrect Options button is displayed for the specified control. The default value is True. Read/write.
