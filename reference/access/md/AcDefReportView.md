# AcDefReportView

**Type:** Enumeration  
**Library:** Microsoft Access 16.0 Object Library  

Use with the DefaultView property to set or return the opening view of a report.

## Constants (2)

- `acDefViewPreview` = 0  
  The report opens in Print Preview.
- `acDefViewReportBrowse` = 1  
  The report opens in Report view.
