# ODBCError

**Type:** Dispatch Interface  
**Library:** Microsoft Excel 16.0 Object Library  
**GUID:** {0002442C-0000-0000-C000-000000000046}  

Represents an ODBC error generated by the most recent ODBC query.

**Remarks:** The ODBCError object is a member of the ODBCErrors collection. If the specified ODBC query runs without error, the ODBCErrors collection is empty. The errors in the collection are indexed in the order in which they're generated by the ODBC data source.

**Example:**

```vba
With Worksheets(1).QueryTables(1)
 .Refresh
 If Application.ODBCErrors.Count > 0 Then
 Set er = Application.ODBCErrors(1)
 MsgBox "The following error occurred:" &
 er.ErrorString & " : " & er.SqlState
 Else
 MsgBox "Query complete: all records returned."
 End If
End With
```
