# XlLink

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the type of link.

## Constants (4)

- `xlExcelLinks` = 1  
  The link is to an Excel worksheet.
- `xlOLELinks` = 2  
  The link is to an OLE source.
- `xlPublishers` = 5  
  Macintosh only.
- `xlSubscribers` = 6  
  Macintosh only.
