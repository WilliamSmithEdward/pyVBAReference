# OLEDBErrors

**Type:** Dispatch Interface  
**Library:** Microsoft Excel 16.0 Object Library  
**GUID:** {00024446-0000-0000-C000-000000000046}  

A collection of OLEDBError objects.

**Remarks:** Each OLEDBError object represents an error returned by the most recent OLE DB query. If the specified OLE DB query runs without error, the OLEDBErrors collection is empty. The errors in the collection are indexed in the order in which they're generated by the OLE DB provider. You cannot add members to the collection.

**Example:**

```vba
For Each objEr in Application.OLEDBErrors
 MsgBox "The following error occurred:" & _
 objEr.ErrorString & " : " & objEr.SqlState
Next objEr
```
