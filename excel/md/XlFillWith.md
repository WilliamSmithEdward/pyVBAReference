# XlFillWith

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies how to copy the range.

## Constants (3)

- `xlFillWithAll` = -4104  
  Copy contents and formats.
- `xlFillWithContents` = 2  
  Copy contents only.
- `xlFillWithFormats` = -4122  
  Copy formats only.
