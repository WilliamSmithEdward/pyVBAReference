# XlBorderWeight

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the weight of the border around a range.

## Constants (4)

- `xlHairline` = 1  
  Hairline (thinnest border).
- `xlMedium` = -4138  
  Medium.
- `xlThick` = 4  
  Thick (widest border).
- `xlThin` = 2  
  Thin.
