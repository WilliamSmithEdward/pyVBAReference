# XlXLMMacroType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies, in a Microsoft Excel version 4 macro worksheet, what type of macro a name refers to or whether the name refers to a macro.

## Constants (3)

- `xlCommand` = 2  
  Custom command.
- `xlFunction` = 1  
  Custom function.
- `xlNotXLM` = 3  
  Not a macro.
