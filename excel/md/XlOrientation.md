# XlOrientation

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the text orientation.

## Constants (4)

- `xlDownward` = -4170  
  Text runs downward.
- `xlHorizontal` = -4128  
  Text runs horizontally.
- `xlUpward` = -4171  
  Text runs upward.
- `xlVertical` = -4166  
  Text runs downward and is centered in the cell.
