# XlArrowHeadLength

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the length of the arrowhead at the end of a line.

## Constants (3)

- `xlArrowHeadLengthLong` = 3  
  Longest arrowhead
- `xlArrowHeadLengthMedium` = -4138  
  Medium-length arrowhead
- `xlArrowHeadLengthShort` = 1  
  Shortest arrowhead
