# XlHighlightChangesTime

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies which set of changes is shown in a shared workbook.

## Constants (3)

- `xlSinceMyLastSave` = 1  
  Show changes made since last save by last user.
- `xlAllChanges` = 2  
  Show all changes.
- `xlNotYetReviewed` = 3  
  Show only changes not yet reviewed.
