# XlFormulaLabel

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the formula label type for the specified range.

## Constants (4)

- `xlNoLabels` = -4142  
  No labels.
- `xlRowLabels` = 1  
  Row labels only.
- `xlColumnLabels` = 2  
  Column labels only.
- `xlMixedLabels` = 3  
  Row and column labels.
