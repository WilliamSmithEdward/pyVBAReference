# OLEDBError

**Type:** Dispatch Interface  
**Library:** Microsoft Excel 16.0 Object Library  
**GUID:** {00024445-0000-0000-C000-000000000046}  

Represents an OLE DB error returned by the most recent OLE DB query.

**Remarks:** The OLEDBError object is a member of the OLEDBErrors collection. If the specified OLE DB query runs without error, the OLEDBErrors collection is empty. The errors in the collection are indexed in the order in which they're generated by the OLE DB provider.

**Example:**

```vba
Set objEr = Application.OLEDBErrors(1)
MsgBox "The following error occurred:" & _
 objEr.ErrorString & " : " & objEr.SqlState
```
