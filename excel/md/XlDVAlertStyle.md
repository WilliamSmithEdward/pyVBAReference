# XlDVAlertStyle

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the icon used in message boxes displayed during validation.

## Constants (3)

- `xlValidAlertStop` = 1  
  Stop icon.
- `xlValidAlertWarning` = 2  
  Warning icon.
- `xlValidAlertInformation` = 3  
  Information icon.
