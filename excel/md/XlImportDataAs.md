# XlImportDataAs

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the format in which to return data from a database.

## Constants (3)

- `xlQueryTable` = 0  
  Returns the data as a QueryTable.
- `xlPivotTableReport` = 1  
  Returns the data as a PivotTable.
- `xlTable` = 2
