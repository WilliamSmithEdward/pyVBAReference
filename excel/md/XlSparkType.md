# XlSparkType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the type of sparkline.

## Constants (3)

- `xlSparkLine` = 1  
  A line chart sparkline.
- `xlSparkColumn` = 2  
  A column chart sparkline.
- `xlSparkColumnStacked100` = 3  
  A win/loss chart sparkline.
