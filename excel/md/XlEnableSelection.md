# XlEnableSelection

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies what can be selected on the sheet.

## Constants (3)

- `xlNoRestrictions` = 0  
  Anything can be selected.
- `xlUnlockedCells` = 1  
  Only unlocked cells can be selected.
- `xlNoSelection` = -4142  
  Nothing can be selected.
