# XlWebSelectionType

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies whether an entire webpage, all tables on the webpage, or only a specific table is imported into a query table.

## Constants (3)

- `xlEntirePage` = 1  
  Entire page
- `xlAllTables` = 2  
  All tables
- `xlSpecifiedTables` = 3  
  Specified tables
