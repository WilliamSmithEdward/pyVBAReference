# PivotLines

**Type:** Dispatch Interface  
**Library:** Microsoft Excel 16.0 Object Library  
**GUID:** {00024481-0000-0000-C000-000000000046}  

The PivotLines object is a collection of lines in a PivotTable, containing all lines on rows or columns of the pivot. Each line is a set of PivotCell objects.
