# XlCorruptLoad

**Type:** Enumeration  
**Library:** Microsoft Excel 16.0 Object Library  

Specifies the processing for a file when it is opened.

## Constants (3)

- `xlNormalLoad` = 0  
  Workbook is opened normally.
- `xlRepairFile` = 1  
  Workbook is opened in repair mode.
- `xlExtractData` = 2  
  Workbook is opened in extract data mode.
